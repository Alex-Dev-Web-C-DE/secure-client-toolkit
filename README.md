# SecureClient Toolkit

A sustainable, privacy-first B2B micro-SaaS platform featuring modular, client-side browser utilities. Designed for secure data processing with **$0 infrastructure cost** and strict data localization (no server-side uploads).

## 🚀 Key Modules
1. **Financial Statement Transformer** — Accounting format standardization.
2. **Marketplace Feed & CSV Sanitizer** — Data cleaning for e-commerce feeds.
3. **VAT / Tax ID Batch Validator** — EU tax compliance checking.
4. **Document & Table Extractor** — PDF data parsing in-browser.
5. **B2B Data Sanitizer** — CRM contact normalization.

## 🛠️ Tech Stack
- Frontend: HTML5, Tailwind CSS, Vanilla JavaScript
- Hosting & Deployment: Cloudflare Pages / Workers (Edge Network)
- Security: 100% Client-side execution (Web APIs, FileReader)
